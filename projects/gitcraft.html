Overview

Gitcraft is a companion reference for developers learning and mastering Git. It explains the mental model behind version control first, then turns it into practical terminal commands and workflows for everyday use. The documentation is organized for quick lookup: branching strategies, collaboration workflows, undo and recovery patterns, and best practices for working in teams.

Built with Zensical, a modern documentation static site generator, the site provides clear navigation, searchable content, and a polished reading experience across desktop and mobile. It's deployed and live at saqibbedar.github.io/gitcraft/.

Highlights

  • 33 documentation pages across 8 topic areas: Getting Started (5 pages), Core Git, Branches (8 pages), Stash, Remotes, Undo and Recovery, Repository Practices, Collaboration, and Open Source workflows.
  • Built with Zensical, a Python-based documentation site generator, with support for extended Markdown, syntax highlighting, tabs, and mermaid diagrams.
  • Deployed to GitHub Pages with automated CI/CD: commits tagged with v* trigger a build and deploy workflow via GitHub Actions.
  • Complete documentation without stubs or placeholders — every section is substantive, 200–700 words per topic, ready for reference and learning.
